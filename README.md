# VV WORK — Платформа з працевлаштування в Європі

Сучасний веборієнтований SPA-додаток для швидкого та прозорого пошуку легальної роботи у країнах ЄС (Польща, Німеччина, Нідерланди, Чехія) та B2B-підбору персоналу для роботодавців.

## 🚀 Технологічний стек

- **Frontend Core:** [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/) (Strict Mode)
- **Збірка:** [Vite 8](https://vitejs.dev/)
- **Стилізація:** [Tailwind CSS v4](https://tailwindcss.com/) (підтримка теми через `@custom-variant dark`, mobile-first адаптивність)
- **Маршрутизація:** [React Router v7](https://reactrouter.com/) (підтримка кириличних роутів `/контакти` та динамичних `/partners/:slug`)
- **Тестування:** [Vitest](https://vitest.dev/) + [@testing-library/react](https://testing-library.com/) + JSDOM + v8 Coverage
- **Іконки:** Локальна векторна SVG-бібліотека (`Icon.tsx`) + Material Symbols Outlined

## 📦 Встановлення та запуск

### 1. Клонування репозиторію та встановлення залежностей:
```bash
npm install
```

### 2. Запуск локального сервера розробки:
```bash
npm run dev
```
Додаток буде доступний за адресою `http://localhost:5173`.

### 3. Запуск юніт-тестів:
```bash
npm test
```

### 4. Запуск юніт-тестів із генерацією звіту покриття (Coverage ≥ 60%):
```bash
npm run test:coverage
```
*Покриття бізнес-логіки та хуків (`useDebounce`, `useAsyncData`, `validation.ts`, `api.ts`) становить **> 98%** (24 тести в 4 тест-сьютах).*

### 5. Збірка для продакшну та попередній перегляд:
```bash
npm run build
npm run preview
```

## 💡 Блок «Мої рішення» (Обґрунтування інженерних та UX рішень)

### 1. Модульна архітектура та чистий поділ обов'язків (Separation of Concerns)
- **Пошук без спаму запитів:** логіку затримки винесено у хук `useDebounce(value, delay)`, що гарантує відсутність надлишкових обчислень під час введення тексту користувачем.
- **Ізоляція валідації:** усі регулярні вирази та правила перевірки (ім'я ≥ 2 символів, телефон у міжнародному форматі `+380...`, Telegram `@username`) винесено в `utils/validation.ts`. Це дозволило досягти 100% тестового покриття валідації без прив'язки до рендерингу компонентів.
- **Керування асинхронними станами:** хук `useAsyncData` стандартизує стани `loading`, `error`, `data` та функцію `execute`, запобігаючи дублюванню коду між компонентами.

### 2. Стійкість до збоїв мережі та інтерактивний QA-стенд
- Сервіс `api.ts` імітує поведінку продакшн-сервера: випадкову затримку 300–800 мс та штучний коефіцієнт помилок (1 з 5 запитів, 20%).
- Для нівелювання збоїв реалізовано утиліту `fetchWithRetry` із захистом від тимчасових мережевих розривів.
- На сторінці [Contacts.tsx](/tz_vv_work/src/pages/Contacts.tsx) вбудовано **інтерактивний QA-монітор**, який дозволяє в реальному часі відстежувати латентність, HTTP-статуси та роботу механізму автоматичних повторних спроб.

### 3. Бездоганна доступність (WCAG 2.1 AA) та SEO
- **Ієрархія заголовків:** чітка послідовність рівнів `<h1>` ➔ `<h2>` ➔ `<h3>` на всіх сторінках без пропусків.
- **Кольоровий контраст:** усунено слабкоконтрастні відтінки (усі текстові елементи мають коефіцієнт контрасту > 7:1 як на світлому, так і на темному фоні).
- **Екранні диктори:** усі інтерактивні елементи мають описові `aria-label`, поля введення зв'язані з відповідними мітками (`htmlFor`), а іконка меню має атрибут `aria-expanded`.
- **Повний комплект метаданих:** у [index.html](/tz_vv_work/index.html) додано `meta name="description"`, `theme-color`, `robots: index, follow` та валідний [robots.txt](/tz_vv_work/public/robots.txt).

### 4. Адаптивність тем і гармонізований дизайн
- Реалізовано перемикання тем через `ThemeContext` із збереженням вибору користувача в `localStorage` та синхронізацією з системними налаштуваннями ОС (`prefers-color-scheme`).
- Векторний компонент [Logo.tsx](/tz_vv_work/src/components/Logo.tsx) автоматично змінює колір літер `VV` (темно-сірий на світлій темі та яскраво-білий на темній), зберігаючи фірмовий електричний синій акцент `WORK`.
- Кнопки дій приведені до єдиного бренд-стилю `bg-blue-600 hover:bg-blue-500 text-white` без випадкових дисонуючих кольорів.

### 5. Продуктивність та оптимізація Core Web Vitals
- **Синхронний початковий рендер:** у каталозі вакансій первинний набір карток генерується синхронно, завдяки чому FCP та LCP відбуваються практично миттєво, а Cumulative Layout Shift (CLS) дорівнює строго **0**.
- **Локалізовані ресурси:** критичні асети (аватар рекрутера, SVG-іконки) зберігаються локально, що виключає затримки на сторонній DNS/TLS-хендшейк.
- **Шрифти без блокування:** стилі підключено з параметром `display=swap`.

### 6. Покриття тестами ≥ 60% (досягнуто > 98%)
- Реалізовано 24 модульних тести, що покривають граничні випадки, роботу таймерів `useDebounce`, валідацію контакту (усі дозволені та заборонені префікси), а також стійкість до відмов сервера.
