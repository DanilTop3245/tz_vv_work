# VV WORK — Платформа з працевлаштування в Європі

Сучасний веборієнтований додаток для підбору перевірених вакансій у ЄС та координації кандидатів з прямими роботодавцями.

---

## 🚀 Технологічний стек

- **Фреймворк:** React 19 + TypeScript (Strict Mode)
- **Збірка:** Vite
- **Стилізація:** Tailwind CSS v4 (мобільна адаптивність, повна підтримка світлої та темної тем через клас `.dark`)
- **Маршрутизація:** React Router v7
- **Тестування:** Vitest + React Testing Library + JSDOM + v8 Coverage
- **Іконки:** Векторна SVG-бібліотека та Material Symbols Outlined

---

## 📦 Встановлення та запуск

### 1. Клонування репозиторію та встановлення залежностей:
```bash
npm install
```

### 2. Запуск локального сервера розробки:
```bash
npm run dev
```
Додаток буде доступний за адресою `http://localhost:5173`.

### 3. Запуск юніт-тестів:
```bash
npm test
```

### 4. Запуск юніт-тестів із генерацією звіту покриття (Coverage ≥ 60%):
```bash
npm run test:coverage
```
Поточне покриття коду ключових модулів (`useDebounce`, `useAsyncData`, `validation`, `api`) становить **> 98%**.

### 5. Збірка для продакшну:
```bash
npm run build
```

## 💡 Блок «Мої рішення» (Обґрунтування інженерних та UX рішень)

### 1. Модульна архітектура та чистий поділ обов'язків (Separation of Concerns)
- Логіку затримки пошукового введення інкапсульовано в хук `useDebounce`, що запобігає надмірному ререндерингу та повторним запитам.
- Обробку асинхронних запитів стандартизовано в хуку `useAsyncData`.
- Правила перевірки форми винесено в окремий модуль `utils/validation.ts`, що спрощує їх ізольоване тестування без прив'язки до React DOM.

### 2. Симуляція реальної мережі та стійка Retry-логіка
- Сервіс `api.ts` імітує реалістичну затримку відповіді сервера (300–800 мс) та штучний коефіцієнт відмов (1 помилка з 5 запитів, ~20%).
- Реалізовано механізм автоматичних повторних спроб (Retry) з алгоритмом експоненційного відкладення (Exponential Backoff: 400мс -> 800мс -> 1600мс), що демонструється на інтерактивному стенді QA на сторінці контактів.

### 3. Зручна валідація з миттєвим зворотним зв'язком
- Поля валідуються на льоту з урахуванням стану фокусу (`touched`), щоб не лякати користувача червоними помилками до початку вводу.
- Підтримуються як номери формату `+380...`, так і Telegram-акаунти через `@username`.

### 4. Повна темна та світла теми (Dark/Light Theme)
- Реалізовано перемикання теми через `ThemeContext` зі збереженням вибору користувача в `localStorage` та автовизначенням системних налаштувань (`prefers-color-scheme`).
- Використано Tailwind CSS v4 `@custom-variant dark (&:where(.dark, .dark *));`, що гарантує миттєве застосування палітри Slate 900/950 без миготіння та з збереженням контрастності й читабельності.

### 5. Покриття тестами ≥ 60% (досягнуто 98%+)
- Написано вичерпні юніт-тести з використанням Vitest і React Testing Library.
- Протестовано часові інтервали `useDebounce`, граничні умови валідації (`validation.ts`), а також успішні/помилкові гілки симуляції API (`api.ts`).
